# Chat Migrate

1. Read this entire conversation. 
2. Extract what was asked, what was found, what was decided, and what was built.
3. Write one continuity prompt in plain prose that states the user's goal, the background needed to act on it, the decisions and preferences already settled, the work finished, and where progress stands right now, so a fresh session resumes without re-asking anything. 
4. Return only that prompt.
